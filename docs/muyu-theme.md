# 电子木鱼主题实现说明

v4.3 / 4.3.0。主题 ID 为 `muyu`，沿用 React、Canvas 2D、Vite 与 Electron，以及原有窗口、主题切换和存档机制。

从仓库根目录运行 `pnpm install --frozen-lockfile`、`pnpm dev`；在主题选择中进入“电子木鱼”。使用 `pnpm desktop` 启动桌面开发版，`pnpm package:mac` 构建 Apple Silicon Mac 包。最新验证与限制见 [v4.3 发布说明](RELEASE-V4.3.md)。

工具栏为“自动、愿想、材质、静念、环境、设置”。“记录”面板已移除；今日/累计计数、手动/自动计数存储字段保留，以兼容已有进度。

## 输入、击中事件与声音

木槌从有效按下开始运动，使用同一条 340ms 时间轴完成短暂蓄力、下落、接触、回弹和回位；接触点在第 100ms，保留 40ms 接触姿态。计数、声音和飘字由统一 `hit` 事件驱动，声音事件不重启动画，背景不参与震动。

- 鼠标左键在木鱼可见区域内按下即开始一次敲击，松开不会再敲一次，持续按住也不重复。灯火、香烟和手串仍在原位置按下并释放后互动；它们的拖动取消阈值为 12 像素。
- 面板打开时场景不接受敲击，按钮和输入框不透传到 Canvas。
- 空格监听只绑定当前木鱼 Canvas；要求 Canvas 已有焦点、应用窗口有焦点、无面板、不处于暂停/隐藏或桌面穿透模式。忽略长按重复、输入法组合及组合快捷键，不注册系统键盘钩子。
- 自动默认关闭、间隔默认 1 秒，可选 0.5/1/2/3 秒。手动点击先取消自动及其尚未发生的接触，再产生一次手动敲击。
- 自动每帧至多产生一次新的输入；停止或恢复窗口时不追补错过的次数。
- 接触前的密集输入共享一次物理下落，每次有效输入仍独立记账；回弹中再次按下从当前姿态继续，不先跳回起始位置。低动效缩短木槌行程、减小转角，接触点不变。
- 快速输入的计数互不覆盖，但同一显示帧的声音合并，音频层另有 35ms 合并窗口与最多 4 个尾音限制。声音和飘字都有数量上限，不将 100 次输入排成随后播放很久的声音队列。

三种声音是本项目原创合成的短促共振音，不是实录木鱼采样。「温润木声」「低沉禅音」「清脆轻响」有不同频率组和衰减。没有背景音乐、连续音轨、音频网络请求，也不会在初次进入时创建音频上下文或播放声音。仅用户交互触发解锁。实际敲击不会等待解锁后补音；显式「试听」可以等待当前一次解锁，并在返回时检查场景仍然有效。

最终音量 = 应用总音量 × 本主题音量，音频层再保留安全余量。关闭主题声音或总声音会停止现有尾音；卸载时关闭音频上下文。自动测试使用模拟音频节点验证调度和生命周期，不能证明人工听感。

## 独立存档和专注

存储键为 `mofish-muyu-v1`，版本字段为 `1`，通过原 `readStore`/`writeStore` 持久化。数据分为：

- `settings`：材质、音色、自动间隔、文案模式和组、自定义文案、字体方向/颜色/大小、飘字、低动效、本主题声音/音量、季节/光阴/灯火/烟雾。
- `stats`：本机日期、今日次数、累计次数、累计手动次数及累计自动次数。
- `focus`：状态、总时长、剩余有效时间及手动/自动/仅环境模式。

`autoEnabled`、待击中输入、音频节点、动画时间和飘字不存档。自动敲击不是一个重启后自动继续的持久化开关。

保存快照将运行中的专注标为暂停，读档也会防御性地将 `running` 改为 `paused`。计时只消耗前台有效时间；切主题、隐藏/最小化、全局暂停及时间步长异常会暂停专注、关闭自动并取消待击中事件。恢复后需明确点击「继续静念」。计时不是根据墙钟到期时间追算，不产生离线收益。

敲击与设置保存约 300ms 合并一次，运行中的专注约 5 秒保存一次；离开/暂停会主动保存。存档缺失或字段损坏仅修复木鱼数据。今日次数以本机日期重置，不改变累计次数；该功能没有历史日历或服务器时间校验。

自定义文案最多 20 条，每条最多 12 个可见字符，使用 `Intl.Segmenter` 按字素计数；控制字符过滤后作为纯文本渲染，绝不作为 HTML 插入。「工资+1」等文字只有显示含义，计数单位始终是敲击次数。

## 美术分层与资源维护

没有使用带 UI 的合成参考图作为整屏运行底图。运行时分别加载房间、八种木鱼、木槌、软垫和灯笼图像；模型换肤不改变交互区域、敲击点或其他设置。图片可见边界与母版尺寸保存在素材清单中，运行尺寸以实际显示需求为准。

窗竹使用独立透明图像。本轮已制作并接入四张正式独立透明道具：`beads-v2.webp`（木纹手串与丝穗）、`candle-v2.webp`（未点燃蜡台）、`lantern-table-v2.webp`（右侧落地台灯）、`incense-v2.webp`（三根竹香）。手串和蜡台不再使用程序几何占位；竹香插入原背景香炉，炉口前沿独立遮住香根。四张 v2 图及其锚点见 `source-art/muyu/README-v2.md` 和 `manifest-v2.json`；原 `README.md` 中的占位说明仅记录初轮状态。

季节粒子、月亮、香烟、蜡烛火焰、局部光和反光仍由 Canvas 程序绘制。香烟改为六条连续曲线（三缕烟各两层），代替原来的 192 段逐段模糊线，随时间连续漂移；未敲击时也由同一动画循环更新。普通画质目标 60fps，低画质目标 30fps，实际帧率取决于设备。房间及夜间/季节材质 sprite 复用缓存；设置对象变化不再无条件重设 Canvas，只有窗口尺寸或渲染缩放实际改变才 resize。

室内结构固定；窗景的雨雪和季节变化受窗口遮罩限制。白天不绘制月亮；灯火全关不绘制火焰及灯光，夜间月亮仍按天时独立显示。夜间在未点亮房间底图上增加相应动态层。当前窗孔遮罩在载入房间时根据色彩与范围计算并缓存；更换房间背景时必须重新核对窗框边缘、镂空和遮罩，不能假定任意新图都可直接套用。

所有主题物件、飘字、接触点与命中都使用同一场景坐标变换。窗口按比例 cover 铺满场景，窄窗口裁去房间两侧，主体不做非等比拉伸。木槌右端适应可见宽度，但敲击点保持不变。

## v4.3 美术与验收边界

暖木房间和经典胡桃使用 v4 日夜分层素材；吊灯、右后灯与前景灯按原参考构图定位，右前景灯保持景深。木槌接触点为场景坐标 (986,350)，动作时间轴与声音共用击中事件。资源来源、锚点和可编辑母版见 `source-art/muyu/README-v2.md`、`README-v3.md`、`README-v4.md`。

灯光、烟、火焰和反光是二维程序效果；音色是本地合成音。单元测试不替代人工听感、长时间性能、多显示器及系统休眠/唤醒的真实设备验收。5/15/25/45 分钟计时的逻辑使用可控时间测试，本次发行检查未对每档重新等待完整时长。
