# 猫咪三维动作样板

用户已批准先完成一只三维样板猫，再按视觉验收结果扩展所有猫咪。

## 目标

用真实四足网格、骨架和蒙皮取代样板猫的二维腿部变形。可编辑母版为 Blender 文件，运行资源为带动画的 GLB。已有猫咪、道具、玩法、UI、存储和其他主题保持原样。

## 实施边界

- 先选结构可靠、许可允许商用和修改的猫模型；保存原文件和许可。禁止把二维变形或刚性几何拼接冒充完整三维蒙皮。
- Blender 已安装在 /Applications/Blender.app，先验证脚本调用与文件导入。
- 样板动作包括待机、行走、转向、起跳与落地。参考用户的视频校准接触时序。商业完成度通过实际画面评审，不以程序测试替代。
- 猫层使用真实三维渲染，可与现有 Canvas 合成以保留背景遮挡和物件排序；不转换整座庭院。
- 试验入口使用不写入存档的预览参数。默认已交付版本保留，样板通过视觉审核后再全量启用。
- 同一动画母版可在正、侧、后和庭院相机下检查。保留脚底接触与位移对应的数据。
- 不发布 GitHub、打包上架或改版本号。

## 验收

1. GLB 存在真实四足骨架、蒙皮权重和动画。
2. 四肢关节方向正确，支撑脚稳定，步频与地面位移同步，转向不切换前后贴图。
3. 草垫跳跃存在后肢蹬地、腾空、前脚着地、后脚跟进；与原场景位置及遮挡一致。
4. 运行截图和录屏检查模型轮廓、脚部与原画风格的差距。明显不合格的模型不替换全部猫咪。
5. 原有项目测试与构建通过，切主题后释放三维资源及循环，无用户存档写入变化。
