# v4.3 · 电子木鱼与五处风景

应用版本 **4.3.0**，在现有锦鲤池、赶海、猫咪庭院、财源广进之外加入“电子木鱼”。沿用原程序的主题选择、窗口控制、鼠标穿透、音量和本机存档。

## 本次更新

- 电子木鱼支持手动与自动敲击；鼠标按下开始动作，接触时统一发声、计数与飘字。长按不重复，快速输入不积压声音，切主题或休眠后不补敲。
- “愿想”提供预设与自定义飘字；“静念”提供 5/15/25/45 分钟计时。工具栏移除独立“记录”面板，保留已有计数和存档。
- 八种独立材质、可独立选择的音色、四季窗景、日夜与灯火；重新调整禅房暖光、灯位、香烛、手串、连续香烟及木槌接触位置。
- 同步此前未发布的主题独立日夜、财神香炉锚点、猫咪道具收纳及草垫动作修改；猫咪庭院移除惊鹿、背景音乐和持续风声，保留互动音效与鸟鸣。
- 猫咪正常启动继续使用原画。三维模型、骨架、工具和 CC BY 3.0 归属随源码保留，仅 `?cat3d=pilot` 或 `?cat3d=all` 启用开发预览；三维外观与部分动作尚未通过视觉验收，未宣称已完成。

## 本次发行验证

- 625 项项目 Node 测试通过，0 失败、0 跳过，覆盖各主题模型、存档、计数、声音调度与动作等逻辑。
- 5 项 Electron 窗口策略测试通过。
- Vite 生产构建通过；已有大于 500 kB 的 chunk 警告仍存在。
- 本次命名修改已在浏览器打开“愿想”“静念”面板验证，UI 操作不额外计数；本机桌面已验证新入口及原有计数保持。

macOS arm64 原生模块、Electron 桌面包、ad-hoc 签名与 ZIP 完整性校验通过；asar 与 Info.plist 均为 4.3.0，24 张木鱼运行素材校验一致。结果见 [发行验证清单](verification/v4.3/release.json)。自动测试不等于全功能人工验收：本次未重新逐一验证原四主题全部玩法、多显示器、真实系统休眠/唤醒、长时间运行及每档完整专注时长。

## 下载与更新

使用 GitHub Release 中的 `yutang-v4.3-mac-arm64.zip`（Apple Silicon Mac），解压后打开“浮生锦鲤池.app”；`SHA256SUMS.txt` 提供下载校验。保留应用标识及原有存档目录，不清空用户数据。

桌面包为 macOS 本地 ad-hoc 签名，未通过 Apple Developer ID 签名或公证。Windows/Linux 桌面安装包未提供。源码可使用 `pnpm install --frozen-lockfile`、`pnpm dev` 启动；Mac 构建命令为 `pnpm package:mac`。
