# 电子木鱼 · 原图画风恢复（2026-10-13）

目标：原图的深胡桃木、蜂蜜/琥珀暖灯光、油润主体局部高光与前后景深。保持独立运行图层，避免整张概念图直接替换场景。

## 新增运行素材

- `room-warm-v4.webp`：1672×941，夜间开灯的暖光反射底图，不含木鱼、木槌、垫、灯具、火焰、烟、月亮。
- `room-day-v4.webp`：1672×941，与上图匹配的中性日间/熄灯底图。
- `walnut-warm-v4.webp`：1024×756，经典胡桃暖灯材质变体；中性原素材保留用于白天和熄灯。透明轮廓 IoU=0.99182。
- `lantern-floor-v4.webp`：692×1024，短脚六边灯；右下正常景深，左下大幅近景虚焦。纸面光独立计算。
- `candles-rear-v4.webp`：1024×736，三支高低烛台，无烘焙火焰；火焰由已有动画系统统一绘制。

以上使用内置 image_gen 生成。母版PNG、透明裁边与挂点JSON一并保留，旧WebP不覆盖。运行图只做裁边、等比缩小和编码。

## 渲染接入

仅修改 `src/themes/muyu/renderer.js`。独立底图缓存、各自的窗景遮罩、有限数量材质/景深缓存；灯火状态同时控制火焰、纸面光、桌面/地面反光、木鱼暖光。恢复前景落地灯与远处烛台层次，烟曲线增加轻微卷曲。木鱼等比缩小至原绘制尺寸的92%，软垫上移22场景像素，接触阴影改为软渐变。场景坐标、命中、IMPACT、敲击时钟、UI、设置与存档代码未修改。

预览：`npm run dev -- --host 127.0.0.1 --port 5188`。

38个木鱼模型/动作/声音测试、5个桌面策略测试通过；Vite、arm64 native、Electron包与签名校验通过。浏览器实测白天、夜晚、熄灯、胡桃/白玉切换、长按1次+短按3次计4次，刷新保持4次；无浏览器警告/错误。桌面实际启动并观察分层画面；桌面试敲一次计数85→86。原四主题两份源文件/资源SHA清单匹配。
